A **unicep** consulta vários serviços de CEP por trás de uma única interface. Se um serviço
cair, ela passa para o próximo e devolve sempre o mesmo objeto `Address`. Funciona no navegador e
no Node.js 20 ou mais novo.

## Sua primeira consulta

```ts
import { Unicep, defaultProviders } from '@unicep/core';

const unicep = new Unicep({ providers: defaultProviders() });

const address = await unicep.lookup('01310-100'); // com ou sem hífen
// {
//   cep: '01310100',
//   street: 'Avenida Paulista',
//   complement: 'de 612 a 1510 - lado par',
//   neighborhood: 'Bela Vista',
//   city: 'São Paulo',
//   state: 'SP',
//   ibgeCode: '3550308',
//   provider: 'viacep'
// }
```

O campo `provider` diz quem respondeu. `complement`, `ibgeCode`, `latitude` e `longitude` podem
não vir, porque nem todo serviço devolve esses dados (só BrasilAPI e AwesomeAPI mandam coordenadas). Em CEPs de cidades inteiras, `street` e `neighborhood` vêm vazios.
