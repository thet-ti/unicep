---
title: Erros
description: Os erros que a unicep lança e como lidar com cada um.
---

Todos os erros da unicep estendem `UnicepError`, então dá para pegar qualquer um deles de uma vez
se você quiser.

| Erro | Quando acontece |
| --- | --- |
| `InvalidCepError` | O valor não é um CEP. Nenhuma requisição é feita. Traz o `input`. |
| `CepNotFoundError` | O CEP está bem escrito, mas nenhum provider conhece. Traz o `cep`. |
| `AllProvidersFailedError` | Nenhum provider conseguiu responder. O `error.errors` tem um erro por provider, na ordem em que foram tentados. |
| `ProviderError` | É o que um provider lança quando falha. Traz o `provider` e a `cause`. |
| `CircuitOpenError` | Um provider foi pulado porque o circuito dele está aberto. Aparece dentro do `AllProvidersFailedError.errors`. |

## Como tratar

```ts
import {
  AllProvidersFailedError,
  CepNotFoundError,
  InvalidCepError,
} from '@unicep/core';

try {
  const address = await unicep.lookup(input);
  mostrar(address);
} catch (error) {
  if (error instanceof InvalidCepError) {
    // peça para a pessoa conferir o CEP
  } else if (error instanceof CepNotFoundError) {
    // o CEP não existe
  } else if (error instanceof AllProvidersFailedError) {
    // todos os serviços estão fora do ar; dê uma olhada em error.errors
    console.warn(error.errors);
  } else {
    throw error; // inclui o motivo de um cancelamento por AbortSignal
  }
}
```

## Cancelamento

Se você passou um `AbortSignal` e cancelou, a promise é rejeitada com o **motivo do
cancelamento** (por padrão, um `AbortError`), e não com um erro da unicep. Isso também não
mexe em nenhum circuit breaker.

## "Não encontrado" ou "falhou"?

A diferença importa, e a unicep tenta ser honesta sobre ela:

- Se todos os providers que responderam disseram que o CEP não existe, o erro é um
  `CepNotFoundError`.
- Se alguns falharam e outros disseram "não encontrado", o erro é um `AllProvidersFailedError`.
  Nesse caso não dá para garantir que o CEP não existe, só que nem todo mundo conseguiu
  responder.
- Provider com o circuito aberto não conta como "respondeu".
