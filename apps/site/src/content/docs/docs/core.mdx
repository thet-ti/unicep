O `@unicep/core` é TypeScript puro, sem dependência de framework. Roda no navegador e no Node.js
20 ou mais novo, com o `fetch` nativo.

## Criando uma instância

```ts
import { Unicep, defaultProviders } from '@unicep/core';

const unicep = new Unicep({
  providers: defaultProviders(),
  timeoutMs: 3000,
  circuitBreaker: { failureThreshold: 3, resetTimeoutMs: 30_000 },
  retry: { attempts: 1, delayMs: 200 },
  cache: { ttlMs: 5 * 60_000, maxEntries: 500 },
});
```

Crie a instância **uma vez** e reutilize. O estado dos circuit breakers e o cache vivem nela.

| Opção | Padrão | O que faz |
| --- | --- | --- |
| `providers` | obrigatório | Os providers, em ordem de prioridade. Os nomes não podem se repetir. |
| `timeoutMs` | `5000` | Quanto esperar cada provider, a cada tentativa. |
| `circuitBreaker.failureThreshold` | `3` | Quantas falhas seguidas até o circuito abrir. |
| `circuitBreaker.resetTimeoutMs` | `30000` | Quanto esperar antes de tentar uma requisição de teste. |
| `retry` | desligado | Veja [Retry](#retry). |
| `cache` | desligado | Veja [Cache](#cache). |

## Consultando

```ts
const address = await unicep.lookup('01310-100');
```

O `lookup(cep, options?)` aceita o CEP com ou sem hífen e devolve uma `Promise<Address>`.

```ts
interface Address {
  cep: string;            // 8 dígitos, sem máscara
  street: string;         // vazio em CEPs de cidades inteiras
  complement?: string;
  neighborhood: string;   // vazio em CEPs de cidades inteiras
  city: string;
  state: string;          // a UF, por exemplo "SP"
  ibgeCode?: string;
  latitude?: number;      // with longitude, when the provider has them
  longitude?: number;
  provider: string;       // quem respondeu
}
```

## Circuito aberto como último recurso

Por padrão, um provider com o circuito aberto é pulado na hora, e a consulta pode falhar por até
`resetTimeoutMs` mesmo que o serviço já tenha voltado. Se você prefere nunca bloquear o usuário,
ligue o `lastResort`:

```ts
const unicep = new Unicep({
  providers: defaultProviders(),
  circuitBreaker: { failureThreshold: 2, resetTimeoutMs: 60_000, lastResort: true },
});
```

Com ele, quando a consulta não deu certo, a unicep ainda tenta os providers que foram pulados (na
ordem de prioridade), sem passar pelo circuit breaker. Se um deles responder, o circuito dele
fecha. Se todos falharem, o erro traz o motivo real de cada um, e não "circuito aberto".

## Estados e cidades

`states()` e `cities(uf)` listam os estados e as cidades de um estado, com o mesmo fallback e os
mesmos circuit breakers da consulta de CEP. O resultado vem ordenado por nome e fica em cache por
24 horas.

```ts
const states = await unicep.states(); // [{ id: 12, uf: 'AC', name: 'Acre' }, ...]
const cities = await unicep.cities('SP'); // [{ name: 'Adamantina', ibgeCode: '3500105' }, ...]
```

Os providers padrão são BrasilAPI e IBGE, nessa ordem. O BrasilAPI divide o circuito com o
provider de CEP de mesmo nome. Use `localities.providers` para trocá-los (veja `LocalityProvider`),
`localities.cache` para ajustar o cache (ou `false` para desligar) e `localitiesStatus()` para ver
os circuitos. `ufs`, `isValidUf()` e `normalizeUf()` também são exportados. Uma UF desconhecida
lança `InvalidStateError`, e se todos os providers falharem o erro é `AllLocalityProvidersFailedError`.

## Retry

Por padrão, um provider que falha é pulado na hora. Para repetir o mesmo provider antes de passar
para o próximo, ligue o `retry`:

```ts
const unicep = new Unicep({
  providers: defaultProviders(),
  retry: {
    attempts: 2,  // tentativas extras por provider, padrão 0
    delayMs: 200, // espera antes da primeira repetição; dobra a cada nova, padrão 200
  },
});
```

Só falhas do provider são repetidas. "CEP não encontrado" e cancelamentos são definitivos. Um
provider que falha em todas as tentativas conta como **uma** falha para o circuit breaker.

## Cache

Ligue o cache em memória para não repetir requisições do mesmo CEP:

```ts
const unicep = new Unicep({
  providers: defaultProviders(),
  cache: {
    ttlMs: 5 * 60_000, // por quanto tempo um endereço é reaproveitado, padrão 5 minutos
    maxEntries: 500,   // quando enche, saem os menos usados, padrão 500
  },
});

unicep.clearCache();
```

Só consultas bem-sucedidas entram no cache (não "não encontrado" nem falhas). CEPs com e sem
hífen usam a mesma entrada, e cada chamada recebe a sua própria cópia do endereço.

## Cancelamento

```ts
const controller = new AbortController();
const promise = unicep.lookup('01310100', { signal: controller.signal });

controller.abort(); // a promise é rejeitada com o motivo do cancelamento
```

Cancelar nunca conta como falha para o circuit breaker.

## Instância compartilhada

```ts
import { getDefaultUnicep } from '@unicep/core';

const unicep = getDefaultUnicep(); // todos os providers embutidos, criada na primeira chamada
```

É a instância que os bindings de React, Vue e Angular usam quando você não passa a sua.

## Helpers

```ts
import { formatCep, isValidCep, normalizeCep } from '@unicep/core';

isValidCep('01310-100'); // true
normalizeCep('01310-100'); // '01310100'
formatCep('01310100'); // '01310-100'
```

## Estado dos circuitos

```ts
unicep.status();
```
