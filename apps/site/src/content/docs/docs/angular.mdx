O `@unicep/angular` traz bindings com signals e com RxJS, para Angular 17 ou mais novo e RxJS 7.
O pacote não usa decorators, então funciona com o build padrão do Angular, sem configuração extra.

## Usando com signals

O `injectCep` precisa rodar num contexto de injeção, como num campo ou no construtor de um
componente ou serviço.

```ts
import { Component, signal } from '@angular/core';
import { injectCep } from '@unicep/angular';

@Component({
  selector: 'app-campo-cep',
  template: `
    <input [value]="valor()" (input)="valor.set($any($event.target).value)" placeholder="00000-000" />
    @if (cep.isLoading()) { <p>Buscando…</p> }
    @if (cep.error(); as error) { <p>{{ error.message }}</p> }
    @if (cep.data(); as endereco) {
      <p>{{ endereco.street }}, {{ endereco.neighborhood }} - {{ endereco.city }}/{{ endereco.state }}</p>
    }
  `,
})
export class CampoCepComponent {
  readonly valor = signal('');
  readonly cep = injectCep(() => this.valor());
}
```

A busca só acontece quando o valor é um CEP completo e válido (com ou sem hífen). Enquanto a
pessoa ainda está digitando, nada é feito. Se o CEP muda no meio da busca, o resultado antigo
some e a requisição anterior é cancelada.

## API

### `injectCep(cep, options?)`

```ts
injectCep(cep: () => string | null | undefined, options?: {
  unicep?: Unicep;           // padrão: a instância fornecida pelo token UNICEP
  enabled?: () => boolean;   // false pausa as consultas, padrão sempre ligado
}): {
  data: Signal<Address | undefined>;
  error: Signal<Error | undefined>;
  isLoading: Signal<boolean>; // true enquanto a consulta do CEP válido atual está em andamento
}
```

### `lookupCep(unicep, cep)`

A versão com Observable, para quem prefere pipelines RxJS. Se você cancelar a inscrição, a
requisição também é cancelada.

```ts
import { inject } from '@angular/core';
import { lookupCep, UNICEP } from '@unicep/angular';

const unicep = inject(UNICEP);
lookupCep(unicep, '01310100').subscribe((endereco) => console.log(endereco));
```

### `UNICEP` e `provideUnicep(unicep)`

O `UNICEP` é o token de injeção da instância do `Unicep`. Por padrão, ele entrega uma instância
compartilhada com todos os providers embutidos. Se você quer mudar os providers, o timeout, o
cache ou o circuit breaker, é só fornecer a sua:

```ts
import { ApplicationConfig } from '@angular/core';
import { Unicep, viaCep, brasilApi } from '@unicep/core';
import { provideUnicep } from '@unicep/angular';

export const appConfig: ApplicationConfig = {
  providers: [
    provideUnicep(new Unicep({ providers: [viaCep(), brasilApi()], timeoutMs: 3000, cache: {} })),
  ],
};
```

O `error` é um dos [erros da unicep](/docs/errors), como `CepNotFoundError` ou
`AllProvidersFailedError`. Todas as opções estão em [Providers](/docs/providers) e no
[Núcleo](/docs/core).
