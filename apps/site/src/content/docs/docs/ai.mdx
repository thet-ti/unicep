Esta documentação foi escrita pensando tanto em pessoas quanto em agentes de IA. Então, se você
prefere deixar o Claude, o ChatGPT, o Cursor ou o Claude Code fazerem o trabalho braçal, dá para
pedir que eles implementem a consulta de CEP no seu projeto, já com o contexto certo.

## Botões em cada página

No topo de cada página tem dois botões:

- **Copiar Markdown** copia o conteúdo da página em Markdown limpo, pronto para colar num chat.
- **Abrir** abre a página direto no Claude, no ChatGPT e em outros, já com um pedido para o
  agente ler a página e te ajudar.

## Arquivos para agentes

| URL | O que tem |
| --- | --- |
| `/llms.txt` | Um índice da documentação, com um resumo do projeto e os links. |
| `/llms-full.txt` | Toda a documentação em português, num único arquivo de texto. |
| `/_llms-txt/english.txt` | A mesma documentação em inglês. |
| `/docs/<página>.md` | Qualquer página em Markdown: é só acrescentar `.md` à URL. |

Se você mandar o agente ler o `/llms-full.txt`, ele já fica com o contexto inteiro de uma vez.

## Prompts prontos

Escolha o seu ambiente, copie o prompt e cole no seu agente. Se preferir, abra direto no Claude
ou no ChatGPT. Cada prompt já vem com um resumo da API e o link da documentação completa, então
o agente não começa do zero.

## Dicas

- Se o seu agente roda no terminal (o Claude Code, por exemplo), cole o prompt direto nele. Ele
  consegue ler a documentação e alterar o seu projeto sozinho.
- Peça para criar a instância do `Unicep` uma vez só e ligar o [cache](/docs/core#cache).
- Dê uma olhada no que foi gerado: veja se os [erros](/docs/errors) estão tratados e se o uso
  dos [providers](/docs/providers#usando-com-responsabilidade) está responsável.
