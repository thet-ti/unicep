This documentation was written with both people and AI agents in mind. So if you would rather
let Claude, ChatGPT, Cursor or Claude Code do the legwork, you can ask them to implement CEP
lookup in your project, with the right context from the start.

## Buttons on every page

At the top of every page there are two buttons:

- **Copy Markdown** copies the page content as clean Markdown, ready to paste into a chat.
- **Open** opens the page straight in Claude, ChatGPT and others, already asking the agent to
  read the page and help you.

## Files for agents

| URL | What is in it |
| --- | --- |
| `/llms.txt` | An index of the documentation, with a project summary and the links. |
| `/_llms-txt/english.txt` | The whole English documentation in a single text file. |
| `/llms-full.txt` | The same documentation in Portuguese (the site's default language). |
| `/en/docs/<page>.md` | Any page as Markdown: just add `.md` to the URL. |

If you point the agent at `/_llms-txt/english.txt`, it gets the whole context at once.

## Tips

- If your agent runs in the terminal (Claude Code, for example), paste the prompt straight into
  it. It can read the documentation and change your project on its own.
- Ask it to create the `Unicep` instance just once and turn on the [cache](/en/docs/core#cache).
- Take a look at what it generated: check that the [errors](/en/docs/errors) are handled and
  that the [use of the providers](/en/docs/providers#using-them-responsibly) is responsible.
